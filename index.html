htmx dashboard Designer over a server table

The server renders a plain table of work items for three teams and sends the dashboard the author last saved; Lattice builds a Board, a Calendar and a Gantt chart over that table with no mount code, and htmx handles the swap, the save and Back. A stand-in server answers htmx's requests in your browser, so nothing leaves the page.

Try the five steps

  1. Built on load. The Designer was declared with saved state; it built a dashboard of a Board, a Calendar and a Gantt over the work-items table.
  2. Swap. Pick a team. hx-get swaps only the source table, and the Board, Calendar and Gantt all refresh from it.
  3. Edit. Drag a widget by its title bar to a new place. lattice:designer-change is posted with hx-post and the server confirms below.
  4. Add a page. Press Add page in the Designer toolbar. The new page is selected and the state is posted again.
  5. Back. Select a page, swap the team, select another page, then press the browser Back button. The earlier team and page return.
